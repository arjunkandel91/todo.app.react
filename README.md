# Todo App
 Simple Todo App using React.js
 
[👉 Demo Link](https://arjunkandel.dev/todo-react/)

This project is a straightforward to-do application crafted in JavaScript. It ensures tasks are preserved using web storage, and it's equipped with essential functionalities such as:

- Adding new task
- Deleting task abd updating task
- Marking tasks as complete
- Searching
- Sorting tasks
- Switching between dark and light theme
